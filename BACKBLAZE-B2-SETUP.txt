WHY DOES THE BUCKET STAY PRIVATE?
-------------------------------------------------------------------------
Backblaze requires a payment method or a one-time $1 fee to make a bucket
public. We do NOT need that. Since you have no card, the app uses a
different delivery path that works 100% free:

  Upload:   Browser -> Next.js -> validate -> B2 buckets (private)
                                          -> Neon saves ONLY {objectKey,
                                             fileUrl, size, mime}
  View:     Browser -> GET /api/upload/{id}/file
                    -> Next.js streams bytes from B2 (SDK, private keys)
           (Neon is NEVER involved in image delivery)
           (B2 is never made public)

The image URL is an unguessable UUID, so "private + proxy" is as safe as
the old public-URL design. Responses are cached at the Vercel edge
(cache-control: public, max-age=31536000, immutable), so repeat views
don't re-download from B2. Vercel Hobby includes 100 GB egress/month —
far beyond this app's usage.

SECURITY:
  - The current App Key has FULL account access. Recommended: create a new
    App Key scoped to ONLY schedly-upload (App Keys -> Add a New Application
    Key -> "allow access to only the bucket" -> read/write) and replace the
    env vars.
  - Never put these credentials in client/browser code or git.
  - Do NOT paste them in chats once deployed (regenerate the key if you do).
